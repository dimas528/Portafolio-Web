# Portafolio-Web

Portafolio personal de Dimas Benitez, desarrollador orientado a Backend y Full Stack Development.

## Sobre el proyecto

Página estática de una sola vista con:

- Sobre mí
- Enfoque (Backend y APIs · Desarrollo Web / Full Stack)
- Proyectos
- Contacto

## Tecnologías

- HTML5, CSS3, JavaScript
- Fuentes: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) (títulos) e [Inter](https://fonts.google.com/specimen/Inter) (texto)
- Sin frameworks ni dependencias — todo en un solo archivo

## Cómo verlo

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```
